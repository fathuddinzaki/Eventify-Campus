Eventify Campus

Aplikasi Manajemen Event Kampus Berbasis Flutter & Firebase

Manage events. Simplify campus life.

Platform Flutter Multi-Platform
Backend Firebase Cloud
Versi 1.0.0
01 — Latar Belakang

Mengapa Eventify Campus?

Pengelolaan Manual

Event kampus masih dicatat secara manual melalui spreadsheet atau grup WhatsApp, sering terjadi miskomunikasi.

Data Tidak Terpusat

Informasi event tersebar di berbagai platform, sulit untuk melacak status dan progress kegiatan.

Solusi Digital

Dibutuhkan aplikasi terpusat yang modern, responsif, dan mudah digunakan untuk manajemen event kampus.

02 — Tujuan Proyek

Tujuan & Sasaran

01

Membangun Aplikasi Mobile Modern

Merancang dan mengembangkan aplikasi manajemen event kampus berbasis Flutter yang berjalan di Android, iOS, Web, dan Desktop.

02

Implementasi CRUD & Real-time Database

Merencanakan operasi Create, Read, Update, Delete dengan Firebase Firestore untuk sinkronisasi data real-time.

03

Sistem Autentikasi Aman

Merencanakan implementasi login dan registrasi pengguna menggunakan Firebase Authentication dengan validasi data.

04

UI/UX Premium & Responsif

Mendesain purwarupa antarmuka dengan estetika modern — glassmorphism, dark mode, animasi smooth, dan typography premium.

03 — Teknologi

Rencana Technology Stack

Flutter

Framework UI cross-platform untuk membangun aplikasi mobile, web, dan desktop dari satu codebase.

SDK ^3.10.4

Firebase

Backend-as-a-Service oleh Google — Authentication, Cloud Firestore, dan hosting.

Auth + Firestore

Provider

State management pattern resmi dari Flutter untuk mengelola state aplikasi secara reaktif dan efisien.

v6.0.5

Google Fonts

Menggunakan font "Outfit" untuk tampilan modern dan profesional di seluruh aplikasi.

Outfit Font

Multi-Platform

Mendukung Android, iOS, Web, Windows, macOS, dan Linux dari satu codebase Dart.

6 Platform

SharedPreferences

Local storage untuk cache data user, event lokal, dan preferensi mode database (Sandbox/Firebase).

Offline-First
04 — Fitur

Rencana Fitur Utama

Autentikasi

Login & Register dengan Firebase Auth + Sandbox Mode

CRUD Event

Tambah, lihat, edit, dan hapus event kampus

Search & Filter

Cari event berdasarkan nama, PIC, atau lokasi dengan filter kategori

Dashboard Statistik

Ringkasan total, aktif, dan selesai dalam stat cards

Dark & Light Mode

Tema otomatis mengikuti sistem perangkat pengguna

Dual Database

Toggle Sandbox (lokal) atau Firebase (cloud) secara dinamis
